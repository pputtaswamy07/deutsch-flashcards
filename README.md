# Deutsch Flashcards

A small German verb flashcard app for studying irregular verbs in the past tense and participle. It includes vocabulary in a clean, mobile-friendly flip-card layout.

## Features

- Flashcards for German verbs
- Filter by A1, A2, and B1
- Shuffle mode and progress tracking
- Mobile-friendly interface for quick study on a phone

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## GitHub Pages publish

This project is configured for GitHub Pages hosting. After pushing the repo to GitHub, enable Pages in the repository settings and select the GitHub Actions or static site deployment flow if available.

If you want the site to be available at a project URL, the app is expected to live under the repo name `deutsch-flashcards`.
